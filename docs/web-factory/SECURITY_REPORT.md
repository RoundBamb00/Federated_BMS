# Security report
Date: 2026-10-16. Scope: client source + build dependencies. Candidate hashes: evidence/source-hashes.json.
PASS within listed scope: npm audit reports zero known vulnerabilities (evidence/npm-audit.json). Dependencies installed with --ignore-scripts; package scripts only Vite, Node tests, Playwright.
Manual source review plus independent reviewer: no fetch/XMLHttpRequest, storage persistence, remote scripts/fonts/assets, eval/Function, dynamic HTML injection, credentials, backend, cloud data or authentication. React escapes device/error/log strings. Port permission requested only by user click. No automatic connect or command. Commands allowlisted to six source-compatible writes. Disabled UI backed by connection-state checks; write success logged only after promise resolves. Telemetry and command acknowledgement are distinct. Logs bounded to 300 entries and 256-byte display per chunk; decoder retains incomplete fixed frame only.
S-001: pending-setup cancellation could leave device open; regression reproduced and fixed. 18 tests pass.
Limitations: no Semgrep/CodeQL CLI available or run; no penetration/hardware test. Wire protocol lacks checksum and ACK; malformed bytes/lost frames can corrupt readings or pack alternation. Read-only parser tests do not certify physical safety. Hosted platform security results not yet inspected. Server/database/payment/authorization scans N/A: those systems do not exist here.
